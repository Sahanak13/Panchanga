# Panchanga — Static HTML/CSS/JS

Simple modern Panchanga site (sun & moon times, moon phase). To publish via GitHub Pages push to a repository named `Panchanga` and enable Pages or use the included workflow.

Quick start:

```bash
cd path/to/Javscript
git init
git add .
git commit -m "Initial Panchanga site"
git remote add origin https://github.com/Sahanak13/Panchanga.git
git branch -M main
git push -u origin main
```

After pushing, GitHub Actions will build and deploy (if you allow Actions). The site will be available at `https://Sahanak13.github.io/Panchanga`.
